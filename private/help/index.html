全部私密文章共用一份授权名单。只有获得博客专用组织访问权限的账号能够读取；普通读者没有修改原文的权限。

作者：如何授权读者

  1. 打开 GitHub 组织成员管理，邀请对方的 GitHub 账号。
  2. 角色选择 Member（普通成员）。不要授予 Owner，也不用单独给仓库添加 Write、Maintain 或 Admin 权限。
  3. 对方接受邀请后，继承该专用组织的 Read 权限，可以阅读全部私密文章。
  4. 读者为自己创建阅读令牌后，如 GitHub 提示需要组织批准，请在组织设置的 Personal access tokens 请求列表中核对并批准仅有 Contents 读取权限的请求。

读者：第一次登录

  1. 先接受作者发给你的 GitHub 组织邀请。
  2. 在 GitHub 新建细粒度阅读令牌。Resource owner 选择 linqopsx-blog，Repository access 只选择 blog-private-drafts。
  3. Repository permissions 中只需 Contents → Read-only；Metadata 读取权限自动添加。请设置一个到期时间。
  4. 如果令牌状态为 Pending，等待作者批准后再登录。
  5. 回到 私密阅读，粘贴你自己账号的令牌。阅读页面只发出读取请求，令牌不会写入网页源码或浏览器持久存储。

作者：继续编辑私人草稿

私人写作后台需要一枚以 linqopsx-blog 为 Resource owner、只选择 blog-private-drafts、Contents 为 Read and write 的作者专用令牌。公开博客的令牌仍以个人账号为 Resource owner，两处分别登录和保存。

取消授权

从博客专用组织中移除对应普通成员，即可取消其今后的读取权限。已经阅读、下载或另行保存的内容无法收回。

登录提示

“令牌无效”通常表示 GitHub 身份校验没有通过；“无读取权限”可能表示邀请尚未接受、令牌未选中本仓库，或请求仍在等待组织管理员批准。不要将令牌发给其他人，读者也不需要作者的写作令牌。
