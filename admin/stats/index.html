访问统计

看看博客最近的访问情况

查看访问次数、文章浏览量、来源网站，以及访客的大致地区和设备。统计面板需要登录你的 Cloudflare 账号。

打开访问统计面板 ↗

统计从启用后开始，历史访问无法补录。刚启用或刚访问后，数据可能需要几分钟才会显示。

进入面板后怎么看

  • Visits / Page views：查看访问次数和页面浏览量，可切换统计日期范围。
  • Path：查看哪些文章和页面被访问得更多。
  • Referer：查看访问来自哪些网站。
  • Country / Device / Browser：查看大致地区、设备类型和浏览器。

这些数据用来了解博客阅读情况，不显示访问者的真实姓名或 GitHub 账号。
