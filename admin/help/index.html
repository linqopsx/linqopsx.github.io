开始在网页上写文章

以后打开写作后台，填写标题、编辑正文、插入图片并保存，就会自动更新博客。

第一次登录：创建写作凭证

后台使用 GitHub 的细粒度访问令牌登录。它相当于只允许修改这个博客仓库的钥匙。

  1. 打开 GitHub 令牌创建页面，确认当前账号为 linqopsx。
  2. Token name 填写 博客写作后台；Expiration 选择一个期限，例如 90 天。
  3. Repository access 选择 Only select repositories，公开写作选择个人账号下的 linqopsx.github.io。私人写作需另外以 linqopsx-blog 为 Resource owner，选择该组织下的 blog-private-drafts。
  4. 在 Permissions → Repository permissions 中，将 Contents 设置为 Read and write。Metadata 的读取权限会自动添加，其他权限不用开启。
  5. 点击 Generate token，复制新令牌。回到后台，点击“使用令牌登录 / Sign In with Token”，把令牌粘贴进去。

令牌保存在当前浏览器中。不要把它发给别人、写进文章或提交到仓库。到期后生成新令牌，再次登录即可。

只读阅读与统一授权

只读阅读入口供读者使用。授权由博客专用组织管理；普通成员只有 Read 权限，无法修改或删除原文。具体步骤见 只读授权说明。

组织中的私密写作需要一枚以 linqopsx-blog 为 Resource owner、只选择 blog-private-drafts、Contents 为 Read and write 的作者令牌。公开文章编辑器继续使用原有个人账号令牌；两处令牌分别保存。

有些文章不想公开怎么办

进入 私人草稿。这个编辑器把文章和图片保存在你的私有仓库中，保存后不会出现在博客首页、搜索、RSS 或公开仓库里。只有获得该私有仓库访问权限的账号才能读取。

后台顶部可以在“公开文章”和“私人草稿”之间切换。两者的保存位置不同，选择前请看页面标题。新草稿默认就保存在私人空间，不需要额外打开隐藏开关。

如果想把某篇私人草稿公开，请在“公开文章”中新建文章，复制正文并上传需要公开的图片，再保存。私人草稿不会自动转为公开文章。

首次进入私人草稿若提示无权访问，请创建以 linqopsx-blog 为 Resource owner 的专用作者令牌，选择 blog-private-drafts 并授予 Contents 读写权限。不要把令牌写进文章。

已经公开过的文章可能仍留在公开仓库历史或他人的副本中；处理旧文章请单独确认。

发布第一篇文章

  1. 选择“文章”，点击新建按钮。
  2. 填写标题、发布时间、分类和标签，在正文编辑器中写作；可以切换可视化和 Markdown 模式。
  3. 通过图片按钮上传图片，也可以到素材库统一管理。
  4. 点击保存并确认。文章会提交到博客仓库，随后自动构建发布。
  5. 打开博客检查结果。后台内的预览用于查看内容，实际页面以发布后的博客为准。

修改文章和个人介绍

已有文章会出现在“文章”列表中，点开编辑后保存即可。“个人介绍 → 关于我”用来修改关于页面。

切换中文界面

后台通常跟随浏览器语言。如果显示英文，登录后打开右上角账户菜单，进入 Settings → Language，选择 Chinese (China) — 中文（中国）。

保存后没有看到更新

先查看 博客发布进度，等待最新任务出现绿色对勾，再刷新博客。如果发布时间设在未来，文章暂时不会显示，而且不会在该时间自动定时发布。

“公开文章”写入公开博客仓库，其文章、图片和修改历史可被他人查看；“私人草稿”写入私有仓库。
