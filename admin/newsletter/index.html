博客更新推送

先更新文章和资源，再发布一条简短公告。邮件服务定期读取公告，通知主动订阅的读者。

发布一条更新公告

用 GitHub 登录并写公告 ↗
  1. 先完成文章或软件资源更新，打开博客检查实际内容已经上线。
  2. 进入 Pages CMS 的更新公告，点击 Add an entry。填写标题、北京时间、邮件更新摘要，以及包含文章链接的详细说明。
  3. 需要通知读者时，开启发布公告（进入邮件订阅源）并保存。开关关闭时只保存公告草稿。
  4. 等待博客发布任务成功，确认公告出现在读者页面，随后由邮件平台定期发送。

普通文章修改、图片上传、软件上传不会自动发邮件。每次要再次通知时新建公告；不要反复修改旧公告的日期或文件名。已经发送的邮件无法撤回。
