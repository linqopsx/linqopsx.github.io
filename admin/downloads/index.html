把软件分享给博客读者

安装包上传到 GitHub 后，会自动显示在博客的“软件下载”页面。也可以复制下载链接，插入你正在写的文章。

在 GitHub 上传安装包 ↗

支持 EXE、MSI、APK、DMG、ZIP 等文件，单个文件需小于 2 GiB。这里的文件公开下载。

第一次上传，按这三步操作

  1. 点击上方按钮，使用你的 GitHub 账号登录，进入已经准备好的“博客软件下载”编辑页面。
  2. 在正文编辑框下方找到 Attach binaries 或 choose your files，选择安装包，等待上传进度完成。文件名建议包含软件名称和版本号。
  3. 在版本说明中记下软件名称和版本，再点击页面底部的 Update release 保存。返回这里点“刷新列表”，再点“复制文章链接”，粘贴到文章的 Markdown 编辑器里即可。

不需要修改标签（Tag）和版本标题，也不需要重新创建令牌。文件传输速度取决于你与 GitHub 的连接。
