#### 终端

- opencode

#### 1. 安装 Node.js

首先访问 Node.js 官网：

[https://nodejs.org/](https://nodejs.org/)

下载 LTS 版本并安装。

安装完成后，win + R 输入 PowerShell 启动终端。

输入：

```plain
node -v
```

查看 Node.js 是否安装成功。

接着输入：

```plain
npm -v
```

如果能够正常输出版本号，说明 npm 已经可以使用。

#### 2. 安装 OpenCode

安装 OpenCode，PowerShell终端输入：

```plain
npm install -g opencode-ai
```

等待安装完成。

#### 3. 验证安装

PowerShell终端输入：

```plain
opencode --version
```

如果终端正常输出版本号，说明安装成功。

#### 4. 启动 OpenCode

PowerShell终端输入：

```plain
opencode
```

即可进入 OpenCode 终端界面。

**作者有话说：**
这些安装有点麻烦，但如果你先安装了dsh，其他的都可以交给它来安装了其实。
