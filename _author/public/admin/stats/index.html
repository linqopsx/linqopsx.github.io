Cloudflare Analytics

看看博客最近的访问情况

查看访问次数、文章浏览量、来源网站，以及访客的大致地区和设备。

打开访问统计面板 ↗

进入面板后怎么看

  • Visits / Page views：查看访问次数和页面浏览量，可切换统计日期范围。
  • Path：查看哪些文章和页面被访问得更多。
  • Referer：查看访问来自哪些网站。
  • Country / Device / Browser：查看大致地区、设备类型和浏览器。

统计从启用后开始，历史访问无法补录。这些数据用来了解博客阅读情况，不显示访问者的真实姓名或 GitHub 账号。
