Cloudflare 原生面板 ↗
只需配置一枚只读令牌即可直接在这里展示统计表：
1. 打开 Cloudflare API Tokens ↗ → 点击 Create Token → Create Custom Token；
2. Permissions 只选 Account → Account Analytics → Read，生成并复制令牌；
3. 在 theodore-blog-author 的 Variables and secrets 中添加 Secret：Key 填 CF_ANALYTICS_TOKEN，勾选 Secret 并 Deploy，刷新本页即可看到完整图表！
