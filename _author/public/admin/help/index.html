使用指南

开始在网页上写文章

打开内置写作台，填写标题、编辑正文、粘贴截图并保存，就会自动更新博客。

打开写作编辑器 →

使用内置写作台（推荐）

  1. 在博客顶部点击「后台」，使用作者 GitHub 账号验证身份后进入 写作后台。
  2. 点击「新建文章」或「管理文章」进入 内置写作编辑器，可在左侧切换公开文章、更新公告与关于我。
  3. 正文支持左右分栏实时预览，可直接按 Ctrl+V 粘贴截图自动上传，点击「保存并发布」后 GitHub Actions 会自动构建并更新博客。

如需使用第三方可视化编辑器，后台底部折叠栏仍保留 Pages CMS 备用入口 ↗ 与 旧版 Sveltia 备用编辑器。

有些文章不想公开怎么办

进入 私人草稿。这个编辑器把文章和图片保存在你的私有仓库中，保存后不会出现在博客首页、搜索、RSS 或公开仓库里。

如果想把某篇私人草稿公开，请在内置写作台的“公开文章”中新建文章，复制正文并上传需要公开的图片再保存。

上传软件安装包

打开 软件上传，点击“在 GitHub 上传安装包”。在正文下方 Attach binaries 区域选择文件并保存 Update release，返回刷新即可复制下载链接或 Markdown 文章链接。

给关注者推送更新与查看统计

打开 更新推送 → 点击「写更新公告」，在内置写作台的更新公告中填写标题、北京时间与摘要，勾选“发布公告（进入邮件订阅源）”保存，邮件 Worker 会每 5 分钟检查并推送给已确认订阅的读者。

打开 访问统计 可登录 Cloudflare 查看访问次数、热门文章与来源；文章评论可在 GitHub Discussions 评论管理 ↗ 回复或清理。
